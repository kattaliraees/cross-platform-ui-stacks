# Cross-Platform UI Stacks: Ranking Matrix

An interactive ranking matrix and comparison of 10 modern cross-platform UI stacks (Flutter, React Native + Expo, Kotlin Multiplatform + Compose, Tauri 2, Dioxus, Slint, Makepad, egui, iced, GPUI) scored across 23 criteria.

## 🚀 Live Demo
View the live interactive ranking tool:
👉 **[https://kattaliraees.github.io/cross-platform-ui-stacks/](https://kattaliraees.github.io/cross-platform-ui-stacks/)**

## 💡 Features
- **Interactive Scoring & Presets**: Adjust category sliders or pick presets (Startup, Lean, Native feel, Agent speed) to dynamically calculate rankings.
- **Filters**: Exclude webview-based stacks or managed runtimes with a single click.
- **Criteria Matrix**: Side-by-side comparison across Reach, Visual Consistency, Native Look, Performance, Language ergonomics, Dev tooling, Ecosystem, Agentic readiness, and Platform integration.
- **Deep-Dive Facts Table**: Breakdown of UI rendering engines, release runtimes, platform support maturity, realistic code-sharing percentages, and trade-offs.
